# Original game audio

Three loopable 32-second compositions: Forest, Harbor and Depths. Twelve synthesized
sound effects provide footsteps, gathering, swings, hits, interface cues,
underwater bubbles and ambient forest/water/fire sound and wolf attack alerts.

All material is generated from original note patterns and synthesis by
`scripts/generate-audio.py` using Python's standard library. There are no sampled
recordings or third-party music licenses. These assets are part of the project's original material. Regenerate with `python3 scripts/generate-audio.py`.
